# Database Seeds

## Responsibility
This directory contains SQL seed scripts for local development environments, test fixtures, and demonstration setups.

### What belongs here:
* Idempotent SQL scripts that seed foundational records (e.g., initial sample targets, standard test profiles).

### What does NOT belong here:
* Real customer or production credentials.
* Production migration logic.

### Future Phase Implementation:
* **Phase 1**: Comprehensive seed datasets representing diverse mock applications (e.g. vulnerable banking API mock target, resilient microservice mock target).
