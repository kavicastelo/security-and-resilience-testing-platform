# Example Test Definitions

## Responsibility
Houses declarative platform-native test definitions that specify executable verification assertions without vendor lock-in.

### What belongs here:
* Declarative YAML test definitions for passive checks, compliance baselines, and performance thresholds.
* Harmless, defense-oriented security verification rules.

### What does NOT belong here:
* Real attack exploit payloads or weaponized vulnerability exploits.
* Raw scanner scripts.
